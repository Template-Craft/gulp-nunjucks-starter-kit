# Editor Setup

The project ships a ready-made VS Code configuration in `.vscode/`:

- `settings.json` — workspace settings (format on save, Prettier, ESLint, Emmet for Nunjucks, etc.);
- `extensions.json` — the recommended extension list (Nunjucks, ESLint, SCSS navigation, Git).

VS Code prompts to install the listed extensions automatically when the project opens.

## Other editors

The project doesn't depend on VS Code — it works fine in any editor, but some automation (format on save, etc.) will need to be set up by hand.
