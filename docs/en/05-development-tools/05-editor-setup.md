# Editor Setup

Starter Kit содержит готовую конфигурацию Visual Studio Code.

После открытия проекта редактор автоматически предложит установить рекомендуемые расширения, а большинство необходимых настроек уже будут применены.

## Цель

Настройка редактора является частью Starter Kit.

Разработчику не требуется самостоятельно искать расширения, настраивать форматирование или подбирать параметры редактора. Всё необходимое уже входит в проект.

## Директория `.vscode`

Проект содержит директорию `.vscode`, в которой находятся:

- `settings.json` — настройки рабочего пространства;
- `extensions.json` — список рекомендуемых расширений.

Эти файлы относятся к репозиторию и используются всеми участниками проекта.

## Рекомендуемые расширения

Starter Kit рекомендует установить расширения, необходимые для комфортной работы с проектом.

Они обеспечивают:

- поддержку Nunjucks;
- форматирование кода;
- интеграцию ESLint;
- навигацию по CSS и SCSS;
- улучшенную работу с Git;
- дополнительные возможности редактора.

Установка расширений не является обязательной, однако рекомендуется для получения полного набора возможностей Starter Kit.

## Настройки рабочего пространства

Workspace Settings автоматически настраивают редактор под соглашения проекта.

Например:

- форматирование при сохранении;
- использование Prettier;
- интеграцию ESLint;
- поддержку Emmet для Nunjucks;
- корректную работу навигации по SCSS и CSS.

Благодаря этому все разработчики работают в одинаковом окружении независимо от локальных настроек редактора.

## Другие редакторы

Starter Kit не зависит от Visual Studio Code.

При использовании другого редактора проект продолжит работать без каких-либо ограничений, однако некоторые возможности автоматизации потребуется настроить самостоятельно.
