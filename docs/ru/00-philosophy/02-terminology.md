# Terminology

В документации используется единая терминология.

Каждый термин имеет строго определённое значение и применяется последовательно во всех разделах документации. Это позволяет избежать неоднозначности при описании архитектуры и внутренних механизмов Build System.

---

## Architectural Approach

Совокупность архитектурных принципов и решений, определяющих организацию проекта независимо от используемых инструментов.

---

## Build System

Реализация архитектурного подхода, автоматизирующая разработку, анализ зависимостей и процесс сборки проекта.

---

## Page

Шаблон, являющийся точкой входа при генерации отдельной HTML-страницы.

---

## Section

Крупный функциональный блок страницы, используемый для её композиции.

Section объединяет связанные элементы интерфейса и может использовать компоненты, данные и другие шаблоны.

---

## Component

Повторно используемый элемент интерфейса с собственной структурой и областью ответственности.

Компоненты могут использоваться различными страницами и секциями.

---

## Template

Инфраструктурный шаблон, предназначенный для решения вспомогательных задач.

Template не является самостоятельной страницей и не представляет отдельный элемент интерфейса.

---

## Data

Структурированные данные, используемые при рендеринге шаблонов.

Источник данных отделён от шаблонов и рассматривается как самостоятельная часть архитектуры.

---

## Template API

Набор соглашений и механизмов взаимодействия между архитектурными элементами проекта.

Template API определяет способ обмена данными и повторного использования шаблонов.

---

## Dependency Graph

Модель зависимостей между архитектурными элементами проекта.

Используется Build System для анализа изменений и определения минимального набора файлов, требующих пересборки.

---

## Incremental Build

Режим сборки, при котором Build System пересобирает только те страницы и ресурсы, на которые повлияли внесённые изменения.

---

## Build Pipeline

Последовательность этапов обработки проекта, выполняемых Build System во время разработки и сборки.
