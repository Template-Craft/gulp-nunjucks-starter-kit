# Data

Data — архитектурная область, отвечающая за содержимое: шаблоны определяют структуру, Data — наполнение. Все JSON-файлы лежат в одном каталоге, независимо от того, какой сущности они принадлежат:

```text
src/views/data/
```

## Уровни данных

Глобальные источники (`Global.json`, `Common.json`) доступны всему проекту. Локальные источники принадлежат конкретной сущности — например, компонент может иметь собственный файл данных с тем же именем, что и сам компонент.

```text
src/views/
├── components/
│   └── Header/
│       └── Header.njk
└── data/
    └── Header.json
```

## Именование

Имя JSON-файла должно полностью совпадать с именем сущности, которой он принадлежит (`Header.json` → компонент `Header`, `about.json` → секция `_about.njk` или страница `about.njk`). Это единственное, что нужно Build System, чтобы связать данные с сущностью — дополнительная конфигурация не требуется.

## Получение данных

```njk
{% set siteData = getData('Global') %}
{{ getData("Header").title }}
```

Build System читает соответствующий JSON-файл и передаёт его содержимое в шаблон через Template API.
