# Templates

Templates — инфраструктурные шаблоны: базовая структура документа, содержимое `<head>`, подключение общих ресурсов. Template не определяет композицию страницы и не является отдельным элементом интерфейса — этим занимаются Pages, Sections и Components.

```text
src/views/templates/
├── _head.njk
└── _scripts.njk
```

## Отличие от Components

Оба используют один шаблонизатор, но решают разные задачи: Component — самостоятельная сущность интерфейса, Template — инфраструктура, которой пользуются другие сущности.

Это не только смысловое различие: Template **не может** вызывать `getComponent(...)` — анализ зависимостей намеренно не отслеживает такие вызовы внутри `templates/`, и связь выпадет из Dependency Graph. Подробности и что делать вместо этого — раздел Development → Templates.

## Подключение

```njk
{% include getTemplate("head") %}
{% include getTemplate("scripts") %}
```

или, если Template оформлен как Nunjucks Macro:

```njk
{% from getTemplate('head') import HTMLHead %}
```

Build System сам преобразует архитектурное имя в путь к файлу — указывать `_` и расширение не нужно.

## Данные

Templates не имеют собственных JSON-файлов. Если шаблону нужны данные — их передаёт вызывающая сущность (Page, Section, Component) либо используются глобальные данные проекта.
