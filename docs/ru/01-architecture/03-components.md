# Components

Component — повторно используемая архитектурная сущность, а не отдельный файл. Это директория, объединяющая всё, что относится к одному элементу интерфейса: шаблон, стили и клиентскую логику — под общим именем.

```text
Header/
├── Header.njk
├── _Header.scss
└── Header.mjs
```

При наличии собственных данных — файл с тем же именем в `src/views/data/`:

```text
src/views/data/
└── Header.json
```

Физически файл лежит в другом каталоге, но архитектурно принадлежит компоненту `Header`.

## Именование

Имя компонента — его уникальный идентификатор. Все файлы, относящиеся к компоненту, используют одно и то же имя — Build System связывает их без дополнительной регистрации или конфигурации.

## Подключение и повторное использование

Component не должен зависеть от места использования и получает данные только через Template API:

```njk
{% include getComponent("Header") %}
```

или, если компонент оформлен как Nunjucks Macro:

```njk
{% from getComponent('Header') import Header %}
```

Component может использоваться любым количеством Sections и Pages без ограничений.
