# Project Structure

Структура каталогов — часть архитектуры, а не вопрос вкуса. Каждый каталог отвечает за один тип сущностей, Build System определяет назначение файла по его расположению, и именно это делает возможным анализ зависимостей без ручной конфигурации.

```text
src/
├── assets/
│   ├── fonts/
│   ├── img/
│   ├── sprites/
│   └── styles/
├── scripts/
│   └── main/
│       └── app.mjs
└── views/
    ├── components/
    ├── data/
    ├── pages/
    ├── sections/
    └── templates/
```

## Архитектурные области

### views/

Шаблоны проекта и связанные с ними данные — основной объект работы Build System, именно здесь определяется структура сайта.

### assets/

Ресурсы для разработки и сборки: стили, изображения, шрифты, SVG-спрайты.

### scripts/

Клиентский JavaScript — отдельная архитектурная область, не смешанная со структурой шаблонов.

## Архитектурные элементы внутри `views/`

- **Pages** — точки входа проекта.
- **Sections** — крупные функциональные части страниц.
- **Components** — повторно используемые элементы интерфейса.
- **Templates** — инфраструктурные шаблоны.
- **Data** — источник данных.
