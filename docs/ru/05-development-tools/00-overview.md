# Development Tools

Готовая среда разработки, интегрированная в Build System и не требующая настройки после `npm install`.

## Что входит

- обработка HTML через Nunjucks;
- обработка SCSS/CSS;
- сборка JavaScript;
- контроль качества кода (ESLint + Prettier);
- автоматическая синхронизация браузера (BrowserSync);
- инкрементальная пересборка и анализ зависимостей;
- системные уведомления о ходе сборки;
- [опциональный Docker](./09-docker.md) — изолированная разработка без Node/npm на хосте;
- дополнительные инструменты (см. Optional Tools).

## Build System vs Development Tools

Build System отвечает за *что* и *когда* собирается. Development Tools — это инструменты, работающие внутри этих задач и помогающие в ежедневной работе (линтинг, форматирование, редактор, уведомления).
