# Development Workflow

```text
Изменение файла → Определение типа → Анализ зависимостей → Инкрементальная пересборка → BrowserSync → Обновление страницы
```

## BrowserSync

Обновляет браузер автоматически после сборки — CSS/изображения точечно (без перезагрузки страницы), HTML/JS — полной перезагрузкой.

## Source Maps

Для SCSS в dev-режиме создаются Source Maps — devtools браузера показывают исходные `.scss`, а не скомпилированный CSS.

## Консоль и уведомления

Build System подробно логирует происходящее в консоль (на языке из `settings.locale`, см. раздел Build System → Настройки); при ошибках дополнительно показывает системное уведомление (`node-notifier`).
