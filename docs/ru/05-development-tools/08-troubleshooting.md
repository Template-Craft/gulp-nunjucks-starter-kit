# Troubleshooting

## Изменения не отображаются в браузере

- Build System запущена (`npm run dev`)?
- есть ли ошибки в консоли?
- файл внутри `src/`?
- если работаете в Docker — см. [раздел Docker](./09-docker.md) про `CHOKIDAR_USEPOLLING` (актуально для macOS/Windows).

## Не пересобралась нужная страница

- правильно ли использован Template API;
- совпадает ли имя сущности с соглашением;
- файл в правильной директории;
- **нет ли внутри `templates/` вызова `getComponent(...)`** — такие связи намеренно не отслеживаются (см. Development → Templates), и это самая частая скрытая причина "страница не обновилась".

Если Build System не может однозначно определить зависимость — выполняется полная пересборка (это fallback, не ошибка).

## Компонент не найден

```njk
{% include getComponent("Header") %}
```

Проверьте: директория существует, регистр имени верный, имя совпадает с соглашением.

## Секция не подключается

```njk
{% include getSection("", "about") %}      {# Landing Page #}
{% include getSection("about", "hero") %}  {# Multipage #}
```

Также проверьте структуру `sections/` и значение `settings.isMultipage`.

## Шаблон не найден

```njk
{% include getTemplate("head") %}
```

Не подключайте Templates напрямую через относительные пути — только через `getTemplate`.

## Данные не обновляются

Проверьте имя JSON-файла, его соответствие соглашению и расположение в `src/views/data`. Изменение `Global.json`/`Common.json` пересобирает весь проект — это ожидаемо.

## Если проблема сохраняется

Начните с первого сообщения об ошибке в консоли — последующие часто следствие первой причины. Если не помогло: полная пересборка (`npm run build`), проверка установленных зависимостей, сверка структуры проекта с соглашениями.
