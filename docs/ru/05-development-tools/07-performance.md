# Performance

Скорость разработки — не побочный эффект, а архитектурное требование: большинство ускоряющих механизмов работают автоматически и не требуют настройки.

## Incremental Build + Dependency Cache

Пересобираются только реально затронутые страницы; карта зависимостей живёт в памяти процесса и обновляется точечно, а не пересчитывается с нуля при каждом изменении (подробности — раздел Build System).

## Что сознательно отключено в dev

- CSSNano (минификация CSS) — только в build;
- beautify HTML — только в build;
- полная production-сборка JS — в dev используется `eval-cheap-module-source-map` + filesystem-кэш webpack.

## Быстрая обратная связь

BrowserSync обновляет страницу сразу после сборки — без ручной перезагрузки.
