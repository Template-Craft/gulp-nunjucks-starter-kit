# Optional Tools

Starter Kit полностью работоспособен без них — это утилиты для сопровождения, не зависимости сборки.

## nsk-tools

Независимый CLI для рутинных задач разработки — создание файлов/каталогов по соглашениям проекта и т.п. Подробности: [nsk-tools](https://github.com/Ko2doo/nsk-tools).

## npm-check-updates

```bash
npm run ncu                       # что устарело
npm run ncu:interactive           # обновить выборочно
npm run ncu:interactive:formatgroup
```

## sass-migrator

```bash
npm run sass:migrator
npm run sass:migrator:imports
```

Миграция синтаксиса Sass при обновлении версии — нужен редко, в основном при переносе старых проектов.
