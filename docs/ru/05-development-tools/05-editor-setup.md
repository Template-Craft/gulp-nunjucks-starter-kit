# Editor Setup

Проект содержит готовую конфигурацию VS Code в `.vscode/`:

- `settings.json` — настройки рабочего пространства (форматирование при сохранении, Prettier, ESLint, Emmet для Nunjucks и т.д.);
- `extensions.json` — список рекомендуемых расширений (Nunjucks, ESLint, SCSS-навигация, Git).

При открытии проекта VS Code сам предложит установить расширения из списка.

## Другие редакторы

Проект не зависит от VS Code — он будет работать в любом редакторе, но часть автоматизации (форматирование при сохранении и т.п.) придётся настроить вручную.
