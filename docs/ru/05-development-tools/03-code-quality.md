# Code Quality

## ESLint

Статический анализ JS/MJS (`eslint.config.mjs`, flat config): синтаксические ошибки, потенциальные баги, неиспользуемый код, нарушение соглашений.

```bash
npm run eslint:status
npm run eslint:fixesAll
```

## Prettier

Автоформатирование — единый стиль независимо от редактора. `eslint-config-prettier` отключает стилистические правила ESLint, которые конфликтовали бы с Prettier, — инструменты не спорят друг с другом.

## Рекомендация

Настройте форматирование при сохранении в редакторе (см. Editor Setup) — тогда об оформлении можно вообще не думать.
