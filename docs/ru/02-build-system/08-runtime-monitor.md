# Runtime Monitor

Во время разработки Build System может автоматически контролировать потребление памяти и процессорного времени.

Runtime Monitor работает параллельно с остальными механизмами Build System и помогает своевременно обнаруживать чрезмерное потребление ресурсов.

## Назначение

Основная задача Runtime Monitor — отслеживать состояние процесса Gulp во время длительной разработки.

При превышении установленных порогов Build System уведомляет разработчика о возможной проблеме.

## Контролируемые параметры

Runtime Monitor отслеживает:

- использование оперативной памяти;
- загрузку процессора.

Пороговые значения задаются через:

```text
gulp/config/settings.mjs
```

## Уведомления

Если использование ресурсов превышает установленные ограничения, Build System:

- выводит сообщение в консоль;
- отображает системное уведомление.

Это позволяет своевременно обнаружить потенциальные утечки памяти или чрезмерную нагрузку процессора.

## Интеграция

Runtime Monitor запускается автоматически вместе с Development Server в режиме разработки.

Дополнительная настройка не требуется.

## Отключение

При необходимости Runtime Monitor можно отключить при запуске Build System с использованием соответствующего параметра командной строки.

В этом случае остальные механизмы Build System продолжают работать без изменений.
