# Runtime Monitor

Во время разработки отслеживает потребление RAM и CPU процессом Gulp и предупреждает, если порог превышен — параллельно с остальными механизмами, без дополнительной настройки.

## Контролируемые параметры

Память (RSS/CPU, через `pidusage`) проверяется раз в `intervalMs` (по умолчанию 10 секунд). Пороги — `settings.monitor.maxMemoryMB` и `maxCpuPercent` (см. раздел Настройки).

## При превышении порога

Build System:

- выводит сообщение в консоль;
- показывает системное уведомление (`node-notifier`).

## Отключение

```bash
gulp --no-monitor
```

или через `npm run dev -- --no-monitor`. Остальные механизмы продолжают работать как обычно.
