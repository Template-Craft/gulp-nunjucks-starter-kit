# Настройки Build System

Build System использует централизованную систему конфигурации.

Все настройки, влияющие на работу механизмов Build System, располагаются в одном месте:

```text
gulp/config/settings.mjs
```

Такой подход позволяет изменять поведение Build System без необходимости редактирования отдельных задач.

## Назначение

Файл `settings.mjs` определяет параметры выполнения Build System.

В зависимости от конфигурации могут изменяться:

- режим проекта;
- работа Dependency Cache;
- параметры Runtime Monitor;
- режим отладки.

Все механизмы Build System используют единый источник конфигурации.

## Режим проекта

Параметр:

```js
isMultipage;
```

определяет архитектурный режим проекта.

Возможны два режима:

- Landing Page;
- Multipage Project.

Некоторые механизмы Build System автоматически адаптируют своё поведение в зависимости от выбранного режима.

## Dependency Cache

Раздел:

```js
settings.cache;
```

управляет поведением Dependency Cache.

Основные параметры:

- автоматическое перестроение кэша при запуске;
- ограничение использования памяти;
- вывод диагностической информации;
- отображение внутренних таблиц зависимостей.

Подробное описание работы Dependency Cache приведено в соответствующем разделе документации.

## Runtime Monitor

Раздел:

```js
settings.monitor;
```

используется Runtime Monitor для контроля потребления системных ресурсов.

Настраиваются:

- максимальный объём используемой памяти;
- допустимая загрузка процессора;
- интервал проверки.

Эти параметры позволяют адаптировать Build System под возможности конкретной рабочей станции.

## Отладка

Параметр:

```js
debug;
```

предназначен для включения дополнительных возможностей диагностики Build System.

Использование данного режима не требуется при обычной разработке и рекомендуется только при анализе внутренней работы Build System.
