# Incremental Build

Пересобирает только те части проекта, которые реально затронуты изменением, используя результат Dependency Analysis вместо полной пересборки.

```text
File Changed
      │
      ▼
Determine Entity
      │
      ▼
Dependency Analysis
      │
      ▼
Affected Pages
      │
      ▼
Rebuild
```

## Область влияния

Изменение Component не означает пересборку всего проекта — пересобираются только Pages, которые используют Sections, содержащие этот Component. Так же и для остальных сущностей (`gulp/tasks/templates.mjs: resolveRenderTargets`).

## Совместная работа с Dependency Cache

Incremental Build не анализирует проект заново при каждом изменении — использует актуальный индекс из Dependency Cache, поэтому определение области влияния занимает примерно постоянное время независимо от размера проекта.

## Если связей не нашлось

Если Build System не может однозначно определить область влияния (например, сущность ещё не встречалась ни в одном известном файле), выполняется полная пересборка всех страниц — это осознанный safe fallback, а не ошибка.
