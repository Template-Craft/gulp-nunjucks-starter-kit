# Watch Mode

Отслеживает изменения исходников во время разработки, определяет затронутые сущности и запускает только нужные этапы сборки — вместо полного цикла.

## Что отслеживается

`gulpfile.mjs` держит отдельные вотчеры на каждую область:

- Templates / Components / Sections / Data (`.njk`, `.json`) — один вотчер, тип изменения определяется по пути файла;
- Styles (`.scss`);
- Scripts (`.js`/`.mjs`);
- Images;
- Fonts.

## Взаимодействие с другими механизмами

Watch Mode сам не решает, что пересобирать — он обнаруживает изменение и передаёт его дальше. Дальнейший анализ (какие сущности затронуты) выполняет система зависимостей (см. Dependency Analysis и Incremental Build).

## Dev-сервер

После обработки изменений BrowserSync автоматически обновляет страницу — вручную перезагружать не нужно.
