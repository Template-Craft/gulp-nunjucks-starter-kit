# Data

Все данные проекта — JSON-файлы в одном каталоге, независимо от того, какой сущности они принадлежат:

```text
src/views/data/
```

## Именование по сущности

| Сущность | Пример |
| --- | --- |
| Page | `pages/about.njk` → `data/about.json` |
| Component | `components/Header/Header.njk` → `data/Header.json` |
| Section | `sections/_about.njk` → `data/about.json` |
| Template | не имеет собственных данных — получает их от вызывающей сущности или из глобальных |

Совпадение имени — единственное, что нужно Build System для автоматической связи данных с сущностью.

## Глобальные данные

```text
Global.json
Common.json
```

Доступны всему проекту. Изменение любого из этих файлов приводит к полной пересборке.

## Получение данных

```njk
{{ getData("Header").title }}
```

## Рекомендации

Храните данные максимально близко к сущности, которой они принадлежат. `Global.json`/`Common.json` — только для данных, действительно общих для всего проекта: это сохраняет слабую связанность и даёт Incremental Build точнее определять область пересборки.
