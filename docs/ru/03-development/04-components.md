# Components

Component — основная единица повторного использования интерфейса: самостоятельная директория со всеми файлами, относящимися к этой сущности.

## Структура

Минимум:

```text
Header/
└── Header.njk
```

На практике — обычно больше:

```text
Header/
├── Header.njk
├── _Header.scss
└── Header.mjs
```

- `Header.njk` — шаблон;
- `_Header.scss` — стили;
- `Header.mjs` — клиентская логика (опционально).

## Именование

Имя директории, шаблона, стилей и скрипта должно совпадать — это единственное, что нужно Build System, чтобы связать компонент с его JSON-данными автоматически, без конфигурации.

## Данные

```text
src/views/data/
└── Header.json
```

Имя JSON-файла должно полностью совпадать с именем компонента.

## Подключение

```njk
{% include getComponent("Header") %}
```

или, если компонент — Nunjucks Macro:

```njk
{% from getComponent('Header') import Header %}
```

Оба варианта учитываются системой анализа зависимостей.

## Incremental Build

Изменение любого файла компонента запускает поиск всех мест использования. Если Component вложен в Section, анализ продолжается и до страниц, использующих эту Section, — пересобираются только реально затронутые страницы.
