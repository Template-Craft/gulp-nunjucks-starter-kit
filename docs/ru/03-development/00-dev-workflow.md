# Development Workflow

Build System задаёт не только процесс сборки, но и рекомендуемый порядок разработки: каждая сущность имеет свою зону ответственности, соглашение об именовании и предсказуемые связи с остальными — это и позволяет Build System анализировать зависимости и делать точечную пересборку.

## Типичный цикл

1. Создать сущность (Page, Section, Component или Template) в соответствующем каталоге.
2. Следовать соглашениям по именованию.
3. Подключить через Template API.
4. Запустить `npm run dev` и работать над своей частью проекта.

Остальное — анализ зависимостей и пересборку — Build System делает сама.

## Incremental Build на практике

После каждого изменения Build System определяет, какие страницы реально затронуты, и обновляет только их — независимо от размера проекта (подробности — в разделе Build System → Incremental Build).
