# Pages

Page — конечная точка сборки: каждый `.njk`-файл в `src/views/pages/` становится отдельным HTML-файлом.

## Создание

```text
src/views/pages/
├── index.njk
├── about.njk
└── contacts.njk
```

Дополнительная регистрация не нужна — достаточно добавить файл.

## Использование

Страница обычно подключает Templates, Sections и глобальные данные. Повторяемую разметку в Page не хранят — для этого есть Components, Sections и Templates.

## Данные страницы

```text
pages/
    about.njk

data/
    about.json
```

Имя JSON-файла должно совпадать с именем страницы — тогда изменение данных пересобирает только её.

## Incremental Build

Изменение самой страницы не требует анализа зависимостей — пересобирается только она.
