# Working with Components

Создавайте Component, когда элемент интерфейса используется больше одного раза или представляет собой самостоятельный логический блок. Структуру директории, именование, данные и подключение (`getComponent`/`from ... import`) см. в разделе Development → Components — здесь те же правила и те же примеры, дублировать их незачем.

## Когда НЕ делать Component

- элемент используется ровно один раз и не является самостоятельным логическим блоком — оставьте разметку внутри Section;
- нужна инфраструктурная разметка, которой пользуются другие сущности (не элемент UI) — это Template, не Component (и Template не может вызывать Component, см. Development → Templates).

## Главное правило

Component отвечает только за свою функциональность — не за логику или структуру страницы. При изменении Build System сама находит все связанные страницы и пересобирает только их.
