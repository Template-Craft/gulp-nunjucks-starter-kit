# Creating a Project

Новый проект начинается не с настройки Build System, а с архитектуры: определите структуру, основные Sections и переиспользуемые Components ещё до первой страницы.

## Порядок действий

1. Создайте первую страницу: `src/views/pages/index.njk` (+ `data/index.json`, если нужны данные).
2. Выберите режим — Landing Page или Multipage (см. ниже) — и выставьте `settings.isMultipage` соответственно.
3. Разбейте страницу на Sections, подключите их через `getSection(...)`.
4. Повторяющиеся элементы вынесите в Components.
5. `npm run dev` — дальше Build System сама отслеживает зависимости.

Структура каталогов и соглашения об именовании — раздел Development → Project Conventions; примеры подключения каждой сущности — соответствующие файлы раздела Development.

## nsk-tools (опционально)

Создание файлов/каталогов можно автоматизировать через независимый CLI **nsk-tools** — это необязательно, чисто для удобства.
