# Working with Data

Соглашение об именовании связывает JSON-файл с сущностью автоматически. Таблицу соответствий (Page/Component/Section/Template) и `getData(...)` см. в разделе Development → Data.

## Рекомендации

- храните данные максимально близко к сущности, которой они принадлежат;
- `Global.json`/`Common.json` — только для действительно общих данных: любое изменение этих файлов пересобирает весь проект;
- у Templates собственных данных не бывает — передавайте их от вызывающей сущности (Page/Section/Component).

Такой подход сохраняет слабую связанность и позволяет Incremental Build точнее определять, что пересобирать.
